# Resource Icons

- Status: Implemented
- Id: 2611122105-resource-icons
- Depends-on: none

## Summary

Gives every resource an icon: a small generated "item" model per resource type (a log stack, an
ingot, a fuel canister, and so on), rendered once at startup into an icon texture the same way
the build menu's building pictures are. The top bar, the hint overlay, and the inventory panel
(see the HUD changeset) use them.

## Motivation

The HUD is moving from words to icons. Resources have no picture of their own yet: the deposit
models are fields of several rocks or trees and read poorly at 24 px, and the refined and
terrain-sourced resources (Iron, Rocket Fuel, Sand, Water) have no model at all. An item model
per resource, rendered like the building pictures, keeps icons in the game's low-poly look
without a second (2D) art pipeline.

## Design

### Item models

One model per `ResourceType`, generated by a new `src/asset-factory/tools/item_gen.py` into
`src/Game/assets/models/items/item_<resource>.glb`, following art-style.md (flat colors, faceted
shading, the shared palette). Each is a single chunky object about 1 unit across, built to read
as a silhouette at small sizes:

| Resource | Item |
|---|---|
| Wood | Three stacked logs with light end rings |
| Stone | A rough gray block with chipped corners |
| Iron Ore | A rock chunk with rust-red veins (the Iron Ore field's colors) |
| Copper Ore | A rock chunk with green and orange veins (the Copper Ore field's colors) |
| Coal | An angular black lump whose upper facets catch the light |
| Crude Oil | A dark barrel with brown bands and a lighter lid |
| Sand | A small tan heap |
| Water | A low-poly teardrop (a lathe, round below and drawn up to a point), leaned away from the game camera so its icon shows the profile |
| Iron | Two stacked gray ingots |
| Rocket Fuel | A white canister with an orange band and a cap |

Previews go through `preview.py` as for every model; the folder README lists them.

### Icons

- `ResourceIcons` renders each item once at startup into a 64 px texture through the same
  offscreen stage as `BuildingPictures` (its own world, the game camera's angle, the world's
  sun), framed tightly so the item fills the square, and caches them. The stage moves out of
  `BuildingPictures` into `PictureStage`, which takes any model path and a framing, and owns the
  draw-once loop both use.
- Coal and crude oil are nearly black, so on the dark UI panel the coal item's upper facets and
  the barrel's body and lid are lifted (their own palette entries) to keep them readable.
- Icons are shown at 20 to 24 UI units, so a 64 px render stays sharp up to the 2x UI scale.
- Headless runs have no icons (as with pictures); UI that shows an icon keeps its size and shows
  nothing in its place.

## Code changes

- `src/asset-factory/tools/item_gen.py`: the ten items; `mesh.py` gains any palette entries they
  need (ingot gray, canister white, fuel orange, water blue).
- `src/Game/assets/models/items/`: the generated models and a README.
- `ModelLibrary`: the item models are required like every other model.
- `Presentation/Ui/PictureStage.cs` (new, from `BuildingPictures`): the stage for any model with
  a framing, and `RenderOnce`; `BuildingPictures` and `TurntableView` use it; `ResourceIcons.cs`
  (new) renders and caches the icons; `GameRoot` creates it (exposed as `Icons`).
- `src/asset-factory/previews/items.png`: the kept preview sheet of all ten items.
- Run the headless import after adding the models and scripts, and commit the `.uid` and
  `.import` files.

## Blueprint updates

## Verification

- `dotnet build game.slnx` and both test suites.
- The previews of the ten items, read at full size and at 24 px.
- The icons as the game renders them, dumped once to PNG (a temporary change, not kept) and read
  at 64 px and at 22 px on the panel color. The HUD changeset shows them on screen.

# Terrain

- Status: Implemented
- Id: 2611100908-terrain
- Depends-on: none

## Summary

Add tile-based terrain (grass, water, mountain) with a fixed test layout, rendered as colored tiles
with a shoreline preview.

## Motivation

Give the ground real structure and the data that later drives passability and varied maps.

## Design

- `TerrainType`: Grass, Water, Mountain. The simulation holds a terrain grid and `TerrainAt(x, z)`.
- A fixed test layout: a water pond (x in [2, 6], z in [-4, 0]) and a mountain cluster at (-6, 2),
  (-6, 3), (-5, 2); everything else grass.
- `TerrainView` builds one tile per cell. `TerrainTiles` renders flat colored placeholders (grass,
  water, a mountain cone on grass) and adds green shoreline strips on a water cell's land-facing
  edges, previewing the transitions that real edge and corner tiles will provide.

## Code changes

- `src/Sim/TerrainType.cs`; `Simulation`: the terrain array, `GenerateTerrain`, `TerrainAt`.
- `src/Presentation/TerrainView.cs`, `src/Presentation/TerrainTiles.cs`; `GameRoot` uses the terrain
  in place of the former flat ground. `src/assets/models/terrain/README.md` lists the CC0 tiles to
  supply.

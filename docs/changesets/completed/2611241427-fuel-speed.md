# Better Fuels Work Faster

- Status: Implemented
- Id: 2611241427-fuel-speed

## Summary

The fuel a building burns now sets how fast it works, as well as how long a unit lasts. Wood is the
baseline; Charcoal works 15% faster and Coal 30% faster.

## Motivation

Today Coal and Charcoal only burn longer than Wood, so a player with a forest has little reason to
mine Coal or run a Charcoal Kiln. A speed boost makes the better fuels worth the effort.

## Design

- **Fuel speed** (`ResourceDef.FuelSpeed`): Wood 1.0, Charcoal 1.15, Coal 1.3. The Fuel Rod is
  1.0 (only the Fission Reactor burns it, and its output is not in scope here).
- **Where it applies:** buildings that make things. `WorkSpeed` multiplies in the fuel speed of
  the unit burning now (`Building.Burning`) for a fuel-burning building that is not a provider.
  With nothing burning, the building is stopped as it is today, so there is nothing to multiply.
  It stacks with the capacity speed: a Coal-fired Smelter in a 0.8 brownout works at 1.04.
- **What it changes:**
  - A Smelter, Glassworks, or Cement Kiln finishes cycles faster (a Smelter's 16 s Iron takes about
    12.3 s on Coal, 13.9 s on Charcoal).
  - A Burner Generator (and the Fission Reactor) supplies the same on every fuel: the boost is left
    out of a provider's speed, so a better fuel only lasts longer there.
- **Burn time is unchanged:** a unit still burns for its `BurnSeconds` of game time whatever the
  speed, so a better fuel both lasts longer and makes more per unit.
- **Best** (the default fuel choice) still picks the longest-burning fuel at hand, which is also the
  fastest, so nothing about the choice changes.
- **Detail panel:** on a building that makes things, the Burning row adds the boost ("Coal, 22 s
  left, +30% speed"); Wood adds nothing. The Fuel picker's note names it too ("Best: burns Coal
  (40 s per unit, +30% speed)").
  The Recipe row keeps the base cycle time.

## Code changes

- `src/Telaelus.Sim/ResourceDefs.cs`: `FuelSpeed` on the fuels.
- `src/Telaelus.Sim/SimulationCapacity.cs`: `WorkSpeed` multiplies in the burning fuel's speed.
- `src/Telaelus/Presentation/Ui/BuildingDetail.cs`: the Burning row and Fuel note text.
- Tests: a Smelter finishing a cycle sooner on Coal and Charcoal than on Wood; a Burner Generator's
  supply the same on Coal as on Wood; the boost stacking with a brownout. Existing fuel tests checked for timings
  that assumed Wood speed on Coal.
- Scenarios whose timings run a furnace on Coal or Charcoal checked.

- Sim and integration tests pass.
- In game: a Smelter's detail panel shows "+30% speed" while burning Coal.

## Implementation notes

- `Simulation.FuelSpeed(building)` is the one place the rule lives; `WorkSpeed` multiplies it in,
  and the panel reads it for the Burning row.
- Two timing tests that ran a furnace on Coal now expect the faster cycle (the Glassworks makes
  four Glass on one Coal instead of three; a Smelter's restarted cycle takes 12.3 s). The
  `crafting-queue` scenario checks the Burning row's "+30% speed"; the Fuel note is not in the
  snapshot, so it was not checked on screen.

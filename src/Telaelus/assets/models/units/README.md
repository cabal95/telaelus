# Unit models

Models for things that move, loaded by the presentation (`TruckViews` for trucks). Generated by the
asset factory (`src/asset-factory/tools/unit_gen.py`, see `docs/asset-pipeline.md`); the look
follows `docs/blueprints/art-style.md`. A unit occupies no cells.

| Unit | File | Size (facing North) | Height |
|---|---|---|---|
| Truck | `truck.glb` | 0.8 wide, 1.6 long | about 0.85 |

- Authored facing North: the front (the cab) is toward -Z. Origin at the unit's center on the
  ground, placed unscaled; the game turns it to its heading.
- The truck's cab is `depot_accent`, like its Depot. Its bed is empty: the game sets the carried
  resource's item model on it (the bed top is at height 0.36, centered 0.29 behind the origin).

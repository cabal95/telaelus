# Character

The player loads `character.tscn` from this folder. `PlayerView` finds its `AnimationPlayer` and
plays clips whose names contain "idle" and "walk"/"run" (case-insensitive). If `character.tscn`
is absent, the player falls back to a capsule.

| File | What it is |
|---|---|
| `character.glb` | The colonist, generated by `src/asset-factory/tools/character_gen.py` (see `docs/asset-pipeline.md`, Animated models) |
| `character.tscn` | An instance of `character.glb`, the scene the game loads |

- About 1.4 tall, facing +Z (south), origin between the feet, placed unscaled. `PlayerView` turns
  its own wrapper node to face the walk.
- Joints, parent first: `hips` (the root, at 0.70), `torso`, `head`, `upper_arm_l`/`_r`,
  `forearm_l`/`_r`, `thigh_l`/`_r`, `shin_l`/`_r`. Each carries one rigid part; nothing bends.
- Clips: `idle` (3 s) and `run` (0.6 s, matched to the player's 6 units a second). Both loop, set
  in `character.glb.import` (`_subresources`).
- Regenerate with `character_gen.py <this folder>`; the `.import` file keeps its settings.
